# base64

Шифруйте и расшифровывайте текст и код всего за пару кликов.

После шифрования вы получаете готовую строку и код. Вы можете сразу вставить и запустить этот код — больше ничего не требуется.

# Usage

[1] Зашифровать: print("Hello, world") = cHJpbnQoIkhlbGxvLCB3b3JsZCIpCg==

[2] Расшифровать: cHJpbnQoIkhlbGxvLCB3b3JsZCIpCg== = print("Hello, world")
