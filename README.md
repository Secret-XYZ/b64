# base64

Encrypt and decrypt text and code in just a couple of clicks.

After encryption, you receive a ready-made string and code. You can paste and run the code immediately; nothing else is required.

# Usage

[1] To encrypt: print("Hello, world") = cHJpbnQoIkhlbGxvLCB3b3JsZCIpCg==

[2] Decrypt: cHJpbnQoIkhlbGxvLCB3b3JsZCIpCg== = print("Hello, world")

# Security

P.S.: Base64 is not encryption. You shouldn't use it to encrypt anything, as anyone can decrypt it. Even AI.
