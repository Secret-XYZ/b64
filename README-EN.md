## Possibilities

- Encoding text and code in Base64
- Convert back in one click
- The resulting string and code immediately after encryption
- You can paste and run the code — nothing else is required.
## Launch

python b64.py
> The script interface is in English. To select an action, simply enter the corresponding number from the menu.

## Menu

| Number | Action       | What does it do                              |
|:-----:|----------------|-----------------------------------------|
| 1   | Encrypt    | Encrypt text or code               |
| 2   | Decrypt    | Decode a Base64 string              |

## Examples

[1] Encrypt

print("Hello, world")  →  cHJpbnQoIkhlbGxvLCB3b3JsZCIpCg==
[2] Decode

cHJpbnQoIkhlbGxvLCB3b3JsZCIpCg==  →  print("Hello, world")
## Important

Base64 is an encoding, not true encryption. It does not protect data from those who know how to decode it.
